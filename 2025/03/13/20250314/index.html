AWS Lambda 使用 Python 套件的紀錄

發表於 2025-03-13 分類於 AWS ， Lambda Disqus： 文章字數： 2.7k 所需閱讀時間 ≈ 7 分鐘

在 AWS Lambda 開發 Python 應用程式時，當遇到以下錯誤時：

表示 Lambda 缺少 PIL（Pillow）套件，需要手動安裝並上傳 Layer。這篇文章記錄解決的方法，以下的範例用安裝 Pillow 舉例，透過製作 AWS Lambda 層所需要的 ZIP 檔案或用 Docker 容器來建置映像檔來解決。

本地安裝套件並壓縮上傳（適用 Linux）

這種方式適合簡單的套件管理，可以在本機完成所有依賴安裝，然後上傳到 AWS Lambda。

  3. 命名資料夾為 python，並壓縮成 ZIP 檔案，上傳到 Layer：

Windows 的限制

  • 上述方法適用於 Linux 環境，但在 Windows 上會缺少相關依賴，導致 Lambda 執行錯誤。例如 pillow 就會缺少 pillow.libs/的資料夾；不過一些較簡單的套件不會有這問題，例如 requests 因為它們只依賴標準 Python 庫。

  • 替代方案：

    1. 用 Docker 快速啟動環境 Amazon Linux，然後建立對應版本的虛擬環境，安裝套件並壓縮成 ZIP。

    2. 使用 docker cp 抓出 ZIP，上傳到 Layer

到 PyPI 下載套件

  1. 前往 PyPI 搜尋 Pillow，並確保選擇對應的 Python 版本（如 3.9）與 Linux 版本

  2. 下載後，將 .whl 副檔名改為 .zip，再解壓縮：

  3. 上傳 package.zip 到 AWS Lambda 層。

其它

  • Lambda 層的固定規則：
    1. 壓縮檔只接受 ZIP 格式。
    2. 壓縮檔內套件的目錄名稱必須為python，否則 Lambda 會無法讀取。
