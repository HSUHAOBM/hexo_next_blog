AWS Bedrock Tool Use：讓 AI 自己決定要呼叫什麼工具

發表於 2026-04-10 分類於 Learn ， AWS Disqus： 文章字數： 2.9k 所需閱讀時間 ≈ 7 分鐘

用 AWS Bedrock 的 Tool Use 功能，讓 AI 模型當「大腦」，自主判斷什麼時候需要什麼資料，主動呼叫本機工具取得即時資訊再回答。本篇以我自己寫的財經新聞 AI 對話系統為例，分享整個實作流程。

Bedrock 和 Tool Use 是什麼

AWS Bedrock 可以把 Claude、Llama、Nova 這類模型包在同一套 API 後面使用，不需要自己架 GPU，也不用自己維護模型服務。

Tool Use 則是讓模型在回答前，可以先要求後端執行某個工具。模型不是真的自己連資料庫或打 API，而是回傳一個 tool_use 指令，後端收到後再去呼叫實際函式，最後把結果送回模型整理成回答。

和 MCP 的差別

Tool Use 比較像「後端自己內建幾個工具給模型用」。如果工具只服務單一系統，這樣就很夠了。

MCP 則比較像把工具獨立成一個 server，讓不同 AI 客戶端都可以接進來用。它彈性比較高，但也多了啟動、部署、權限管理這些事情。

我這次只是要讓自己的 Flask app 能查本機新聞和市場資料，所以先用 Bedrock Tool Use 就好。
